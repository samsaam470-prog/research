# research — Interview Research Platform Frontend

Plain HTML/CSS/JS frontend for the Interview Research Platform backend.

## Backend
`https://thistimebackendislattime.protfilio.workers.dev`

## Pages
- `index.html` — login
- `dashboard.html` — admin overview
- `builder.html` — create/edit interviews
- `interview.html` — public participant page
- `thanks.html` — post-submission confirmation

## Deploy
Connect this repo to Cloudflare Pages. No build command. Build output directory: `/`.
